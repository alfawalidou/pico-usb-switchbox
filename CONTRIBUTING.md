# Contributing

Contributions that improve firmware reliability, USB HID behavior, hardware documentation, or examples are welcome.

## Guidelines

- Keep hardware and firmware changes focused.
- Document pin assignments, board revisions, and dependency changes.
- Do not commit credentials, tokens, or machine-specific secrets.
- Include reproduction steps for HID, USB enumeration, or input issues.
- Test changes on the intended Raspberry Pi Pico/Pico-compatible target when possible.

Pull requests should explain what changed, why it is useful, and how it was validated.
